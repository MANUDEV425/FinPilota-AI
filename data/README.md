# Data Directory

This directory contains financial datasets and sample documents for FinancePilot AI.

## ML Training Data

The machine learning model uses the UCI Default of Credit Card Clients dataset:
- Source: https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients
- License: CC BY 4.0
- Description: Historical Taiwanese credit card client data from 2005
- Target: Next-month default payment (Yes/No)

**Important Limitations:**
- This dataset is historical and not validated for Indian borrowers
- It is not a model of company financial health
- Use for demonstration and educational purposes only
